= How Zimlets work

A xref:glossary.adoc#zimlet[Zimlet] adds your own features to the xref:glossary.adoc#modern-ui[Modern UI] as JavaScript that the Modern UI loads and runs in the browser. You build it from source files, and an administrator deploys it to the Zimbra server.

[#from-source-to-modern-ui]
== From source to Modern UI

You write your Zimlet as source files. The `zimlet` tool builds them into one file and packages it. An administrator deploys the package. Then the Modern UI loads your Zimlet and sets it up. What the Zimlet adds then takes effect. Most often that is new UI in existing screens, but a Zimlet can also add behaviour only and show nothing.

== A bundle and a descriptor

`zimlet build` compiles your source files, starting at `src/index.js`, into one JavaScript file: `build/index.js`. `zimlet package` writes a small XML xref:glossary.adoc#descriptor[descriptor] next to it and zips the build folder.

The descriptor tells the Zimbra server what the Zimlet is. It holds the name, version, label and description, the files to load, and the range of Modern UI versions the Zimlet works with. You pass the name, version and range to `zimlet package`. The label and description come from `src/intl/en_US.json`. See xref:build-and-package.adoc[Build and package].

== How a Zimlet adds to a screen

Modern UI screens contain named xref:glossary.adoc#slot[*slots*]. A slot is a place where a Zimlet can add content. Your Zimlet registers an xref:glossary.adoc#plugin[plugin handler] for a slot, and the Modern UI displays what the handler returns. Other registrations add a settings section or change message content.

See xref:factory-and-lifecycle.adoc[Factory and lifecycle] for how a Zimlet starts and registers, and xref:extending-the-ui.adoc[Extend the UI with slots] for slots.

== Shared libraries

The Modern UI already contains libraries such as Preact. Import them as usual, and your Zimlet uses the Modern UI's copy instead of bundling its own. Any other library you import is added to your bundle and makes it larger. See xref:shared-libraries.adoc[Shared libraries and imports].

[#try-it-while-you-develop]
== Try it while you develop

`zimlet watch` serves your Zimlet from your machine. A helper Zimlet called the xref:glossary.adoc#sideloader[*sideloader*] loads it into the Modern UI. When you save a file, `zimlet watch` rebuilds the Zimlet and serves the new version. The open Modern UI page keeps the old version, so reload the page to see the change. Keep *Persist on Reload* ticked in the sideloader so the Zimlet loads again after the reload. See xref:run-and-debug.adoc[Run and debug].
