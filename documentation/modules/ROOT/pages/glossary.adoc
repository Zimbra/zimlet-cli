= Glossary

Short definitions of the terms the guide uses. Each entry links to the page that covers the topic.

[[cos]]
== Class of service (COS)

A set of account settings on the Zimbra server that applies to a group of accounts. A COS lists the Zimlets its accounts can use. Each Zimlet is mandatory, enabled by default or disabled by default. Users can switch off a Zimlet that is not mandatory. See xref:deploy.adoc[Deploy].

[[context]]
== Context

The object that the Modern UI passes to your Zimlet's xref:glossary.adoc#factory[factory]. It holds what the Zimlet needs to work with the Modern UI. For example, `plugins` registers xref:glossary.adoc#plugin[plugin handlers]. See xref:factory-and-lifecycle.adoc[Factory and lifecycle].

[[descriptor]]
== Descriptor

The XML file that `zimlet package` generates. It holds the Zimlet name, version, label, description and xref:glossary.adoc#semver-range[semver range]. It also lists the files of the build. The Zimbra server reads it when an administrator deploys the Zimlet. See xref:build-and-package.adoc[Build and package].

[[factory]]
== Factory

The default export of your entry file. The Modern UI calls it with the xref:glossary.adoc#context[context] and expects an object back. It then calls the `init()` method of that object once. See xref:factory-and-lifecycle.adoc[Factory and lifecycle].

[[hmr]]
== Hot module replacement (HMR)

A development feature of `zimlet watch` intended to update a running Zimlet without a page reload. In the sideloader check on the Modern UI, the open page did not update on save, so reload the page to see the change. HMR runs only in development, not in a production build. See xref:run-and-debug.adoc[Run and debug].

[[modern-ui]]
== Modern UI

The Zimbra web client that loads and runs Zimlets. Its screens contain xref:glossary.adoc#slot[slots] where Zimlets add content.

[[plugin]]
== Plugin and plugin handler

A plugin handler is a function that your Zimlet registers under a key with `plugins.register`. For a key such as `slot::<slot-name>`, the Modern UI calls the handler and shows its result in the matching xref:glossary.adoc#slot[slot]. Other keys, such as `settings` and `messageProcessors:<kind>`, are read at other places in the Modern UI. See xref:extending-the-ui.adoc[Extend the UI with slots].

[[semver-range]]
== Semver range

A version range in npm style, such as `^4.42.0`. You set it with the `--zimbraXVersion` option of `zimlet package`. The option is optional. Without it, the range is `>=1.0.0`, which accepts every Modern UI version. The range states which Modern UI versions your Zimlet works with. The server leaves out a Zimlet whose range does not include the running Modern UI version. See xref:build-and-package.adoc[Build and package].

[[shim]]
== Shim

A small module that stands in for a shared library at build time. `zimlet build` replaces an import such as `preact` with a shim that reads the library from the Modern UI at run time. Your Zimlet uses the Modern UI's own copy and does not bundle another. See xref:shared-libraries.adoc[Shared libraries and imports].

[[sideloader]]
== Sideloader

A Zimlet that loads another Zimlet from a URL you enter, such as the address that `zimlet watch` serves. Use it to try a Zimlet in the Modern UI without packaging and deploying it. See xref:run-and-debug.adoc[Run and debug].

[[slot]]
== Slot

A named place in a Modern UI screen where Zimlets can add content. A slot calls the xref:glossary.adoc#plugin[plugin handlers] registered for it and shows their results. See xref:extending-the-ui.adoc[Extend the UI with slots].

[[vertical]]
== Vertical

A top-level area of the Modern UI with its own entry in the main navigation. Mail, Calendar, Contacts, Briefcase and Settings are built in. A Zimlet can add four more: Video apps, Chat apps, Cloud storage apps and Integrations. Each exists only while at least one Zimlet registers for it. See xref:extending-the-ui.adoc[Extend the UI with slots].

[[zimlet]]
== Zimlet

An extension of the xref:glossary.adoc#modern-ui[Modern UI]. It is one JavaScript bundle and a xref:glossary.adoc#descriptor[descriptor], packaged in a zip file. The Modern UI loads and runs it in the browser. A Zimlet can add content to existing screens, new screens, settings and event handling. See xref:concepts.adoc[How Zimlets work].

[[zmzimletctl]]
== `zmzimletctl`

The command-line tool on the Zimbra server that an administrator uses to deploy and manage Zimlets. `zmzimletctl deploy <zimlet.zip>` installs the Zimlet files, adds the Zimlet to the server, grants it on the default xref:glossary.adoc#cos[COS] and enables it. Other commands include `undeploy`, `enable`, `disable`, `acl`, `configure` and `listZimlets`. See xref:deploy.adoc[Deploy].
