= Help and migration

This part helps when a xref:reference/glossary.adoc#zimlet[Zimlet] does not work, when you have a question, or when you move from an older kind of Zimlet. Each page starts from a symptom or a question, not from a feature, and points to the page that owns the fix. Use it when you are stuck, and before you ask for help.
