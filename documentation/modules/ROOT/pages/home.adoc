== Building Zimlets

=== Getting Started

Zimlets are essentially Preact components that run in a sandbox within the main Zimbra X application. To build them, you need to link:https://github.com/Zimbra/zimlet-cli/wiki/Setup-A-Development-Environment[set up a development environment] and should review the link:https://github.com/Zimbra/zimlet-cli/wiki/Suggested-Reading[suggested reading].

=== Zimlet Slots

Throughout the Zimbra X app, hooks called `ZimletSlots` allow Zimlets to inject components into the app.

==== Seeing available zimlet slots

To see which slots are available in the UI, add the query string `?zimletSlots=show` to the end of your URL for the webmail client, for example, `https://localhost:8080/?zimletSlots=show`. This shows all of the places in the active UI where ZimletSlots are available, such as the `menu` slot:

image::showSlot.png[show slot]

Slots that are not visible, such as the `routes` slot, which allows you to add URL routes to screens in the app, display a message in the browser console:

----

----

The `ZimletSlot`s remain visible until you refresh the page without the `zimletSlots=show` query string.

=== Running a zimlet

[NOTE]
====
Prerequisite: a running Zimbra X UI, such as https://localhost:8080.
====

. Create a zimlet, and run `zimlet watch`.
. Navigate to `https://localhost:8080/sdk/zimlets`.
. Enter any name for the Zimlet and the URL output by the watch command, then click "Load Zimlet".
. Navigate to `https://localhost:8080`; the Zimlet should be included in the UI.

Main article: link:https://github.com/Zimbra/zimlet-cli/wiki/Packaging-and-Deploying-Zimlets[Packaging and Deploying Zimlets]

=== Zimlet Lifecycle

The Zimlet calls functions over its lifecycle, such as when it loads and unloads. The app passes `context` into the Zimlet so it can interact with the main app. See the link:https://github.com/Zimbra/zimlet-cli/wiki/Zimlet-Context[Zimlet Context documentation] for more details.

[source,js]
----
include::example$home-zimlet-lifecycle.jsx[]
----

Lifecycle methods allow the Zimlet to set itself up, add content to the page, and clean itself up when it is unloaded.

==== Gotchas

The Zimlet is evaluated in a separate window with a clean environment. Common global values such as `window.location` are not available. Instead, many global values are available in the Redux store.

=== Styling Zimlets

The link:https://github.com/Zimbra/zm-x-ui[`@zimbra/zm-x-ui`] package has many styles and mixins for styling Zimlets.
