= Zimlet developer guide

Extend the Zimbra Modern UI with features of your own, from setting up your development environment to deploying a Zimlet on a Zimbra server.

== What is a Zimlet

A xref:glossary.adoc#zimlet[Zimlet] is a small JavaScript program that the xref:glossary.adoc#modern-ui[Modern UI] loads in the browser. It adds to screens that already exist, for example content in a message, a menu item or a settings section. An administrator deploys the Zimlet to the Zimbra server and enables it for the accounts that use it.

[#who-this-guide-is-for]
== Who this guide is for

This guide is for anyone who wants to extend the Modern UI with a new feature. You can be a Zimbra developer or come from outside Zimbra. You need working knowledge of JavaScript and Node.js. Use Preact and JSX for the user interface. The Modern UI is built with Preact, and the Zimlets that Zimbra provides use it. Other frameworks may have limitations. See xref:prerequisites.adoc[What you need before you start] for the full list.

If you only deploy a Zimlet that someone else built, you are an administrator. Start with xref:deploy.adoc[Deploy].

== What you will build

You build a working Zimlet. You create it from a template, run it in the Modern UI while you develop, and package it as a zip file. You then deploy the zip file to a Zimbra server.
