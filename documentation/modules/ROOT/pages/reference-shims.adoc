= Modules, components and enhancers

Look up every module that the Modern UI provides to a Zimlet, and the UI components and enhancers you can import from it.

[#how-imports-work]
== How imports work

A *shim* is a module that the Modern UI provides, so your Zimlet does not bundle its own copy. Import these modules as usual. Do not add them to `package.json`.

A library that is not in the module table below is bundled into your Zimlet. Import `createElement` from `preact` in every file that contains JSX.

If you import a name that the Modern UI does not provide, the build can still succeed. The Zimlet then fails when it uses that name. The failure can be silent, with nothing rendered and no error in the console, or it can throw an error. Import only the names in the tables on this page and in xref:reference-apis-hooks.adoc[APIs and hooks]. `react` and `react-dom` are replaced by `preact/compat` at build time.

[#module-table]
== Module table

[[preact]]pass:[<a class="anchor" href="#preact"></a>]`preact`, `preact/hooks`, `preact/compat`::
The Preact of the Modern UI. Use `preact` for components, JSX and `createElement`, `preact/hooks` for hooks such as `useState` and `useEffect`, and `preact/compat` for libraries written for React. See the https://preactjs.com/guide/v10/getting-started[Preact guide], https://preactjs.com/guide/v10/hooks[Hooks] and https://preactjs.com/guide/v10/switching-to-preact[Switching to Preact].

[[zimbra-preact-i18n]]pass:[<a class="anchor" href="#zimbra-preact-i18n"></a>]`@zimbra/preact-i18n`::
Translation helpers, such as `Text`, `Localizer` and `useText`. Use them to show text from your Zimlet's language files in the language of the user. See xref:localization.adoc[Localization].

[[preact-markup]]pass:[<a class="anchor" href="#preact-markup"></a>]`preact-markup`, `preact-render-to-string`::
`preact-markup` renders an HTML string as components. Use it to show HTML text, such as a formatted message. `preact-render-to-string` renders components to an HTML string. Use it when you need the markup as text. See the https://github.com/developit/preact-markup[preact-markup] and https://github.com/preactjs/preact-render-to-string[preact-render-to-string] documentation.

[[react-redux]]pass:[<a class="anchor" href="#react-redux"></a>]`react-redux`::
Only `Provider`, `connect`, `useSelector`, `useDispatch` and `batch`. Use them to read and change the Redux state that the Modern UI shares: `useSelector` and `useDispatch` in function components, `connect` in class components. See the https://react-redux.js.org/api/hooks[React Redux hooks] and xref:data-and-state.adoc[Data and state].

[[redux-actions]]pass:[<a class="anchor" href="#redux-actions"></a>]`redux-actions`::
The whole module. Use it to create action creators and reducers with less code, for example when you add state for your Zimlet. See the https://redux-actions.js.org/[redux-actions documentation].

[[apollo-client]]pass:[<a class="anchor" href="#apollo-client"></a>]`@apollo/client`, `@apollo/client/react/hoc`, `@apollo/client/react/components`::
The whole modules. Use them to run your own GraphQL queries and mutations when no ready-made hook does what you need. Prefer the ready-made hooks. See the https://www.apollographql.com/docs/react/[Apollo Client documentation] and xref:reference-apis-hooks.adoc#call-the-server[Call the server].

[[moment]]pass:[<a class="anchor" href="#moment"></a>]`moment`, `dompurify`::
The instances that the Modern UI uses. Use `moment` to parse, format and calculate dates and times. Use `dompurify` to clean an HTML string of unsafe markup before you show it. See the https://momentjs.com/docs/[Moment.js documentation] and the https://github.com/cure53/DOMPurify[DOMPurify documentation].

[[preact-router]]pass:[<a class="anchor" href="#preact-router"></a>]`preact-router`::
Only `route` and `Link`. Use `route(url)` to go to another screen from code, and `Link` for a link that does not reload the page. Zimlets must use the router of the Modern UI. See the https://github.com/preactjs/preact-router[preact-router documentation].

[[preact-router-match]]pass:[<a class="anchor" href="#preact-router-match"></a>]`preact-router/match`::
Only `Match`. Use it to render content or a style, such as an active link, depending on whether the current URL matches a path. See the https://github.com/preactjs/preact-router[preact-router documentation].

[[zimbra-client-blocks]]pass:[<a class="anchor" href="#zimbra-client-blocks"></a>]`@zimbra-client/blocks`::
The whole `@zimbra/blocks` UI kit, for example `Button`, `Dialog`, `Icon`, `Popover`, `Select`, `Spinner`, `Tabs` and `Tooltip`. Use it for the basic building blocks of your interface, so that your Zimlet looks like the Modern UI. See xref:reference-blocks.adoc[Blocks UI kit] for every export.

[[zimbra-client-components]]pass:[<a class="anchor" href="#zimbra-client-components"></a>]`@zimbra-client/components`::
Components of the Modern UI. Use them to add menus, forms, dialogs and lists that match the rest of the Modern UI. See <<ui-components>>.

[[zimbra-client-enhancers]]pass:[<a class="anchor" href="#zimbra-client-enhancers"></a>]`@zimbra-client/enhancers`::
Wrappers that add props to a component. Use them to get data such as a media query result, configuration values or the translation context into a component. See <<enhancers>>.

[[zimbra-client-graphql]]pass:[<a class="anchor" href="#zimbra-client-graphql"></a>]`@zimbra-client/graphql`::
Ready-made queries, mutations and wrappers. Use them only when no ready-made hook covers your need. See <<graphql-module>>.

[[zimbra-client-hooks]]pass:[<a class="anchor" href="#zimbra-client-hooks"></a>]`@zimbra-client/hooks`, `@zimbra-client/hooks/graphql`::
Ready-made hooks. Use them in function components to read configuration and preferences, and to read or change mail, folders, calendars and other account data. See xref:reference-apis-hooks.adoc#hooks-general[APIs and hooks].

[[zimbra-client-util]]pass:[<a class="anchor" href="#zimbra-client-util"></a>]`@zimbra-client/util`, `@zimbra-client/util/contacts`::
Helper functions and `zimletEventEmitter`. Use them for common tasks, such as delaying a call with `debounce`, and to react to events of the Modern UI, such as a sent message. See xref:reference-apis-hooks.adoc#utilities[APIs and hooks].

[[zimbra-client-constants]]pass:[<a class="anchor" href="#zimbra-client-constants"></a>]`@zimbra-client/constants`::
Constants, such as event names and folder ids. Use them instead of typing these values yourself. See xref:reference-apis-hooks.adoc#constants[APIs and hooks].

[[zimbra-client-errors]]pass:[<a class="anchor" href="#zimbra-client-errors"></a>]`@zimbra-client/errors`::
`errorMessage` and `faultCode`. Use them to show a readable message for a failed call, or to decide how to react to the Zimbra fault code. See xref:reference-apis-hooks.adoc#errors[APIs and hooks].

[[zimbra-client-platform]]pass:[<a class="anchor" href="#zimbra-client-platform"></a>]`@zimbra-client/platform`, `@zimbra-client/browser`, `@zimbra-client/pwa-utils`::
Platform checks and browser helpers. Use them when your Zimlet behaves differently on the web, in the desktop app or as an installed web app, or when it opens an external link. See xref:reference-apis-hooks.adoc#platform-and-browser[APIs and hooks].

[#ui-components]
== UI components

Import from `@zimbra-client/components`.

[[action-button]]pass:[<a class="anchor" href="#action-button"></a>]`ActionButton`::
Show a button with an optional icon and text. Use it for a standard action button, such as a toolbar action, that looks like the Modern UI buttons.

[[naked-button]]pass:[<a class="anchor" href="#naked-button"></a>]`NakedButton`::
Show a button without button styling. Use it when the content, such as an icon or a link-style label, must be clickable but not look like a button.

[[close-button]]pass:[<a class="anchor" href="#close-button"></a>]`CloseButton`::
Show a close button. Use it to close a dialog, a panel or a message.

[[help-button]]pass:[<a class="anchor" href="#help-button"></a>]`HelpButton`::
Show a button that opens a help popover. Use it next to a field or a setting that needs a short explanation.

[[add-more]]pass:[<a class="anchor" href="#add-more"></a>]`AddMore`::
Show a button with a label, to add another row to a form. Use it in a settings form where the user can enter a list of values.

[[action-menu]]pass:[<a class="anchor" href="#action-menu"></a>]`ActionMenu`::
Show a drop-down menu of actions. Use it for a "more" menu or a menu button. Fill it with <<action-menu-item,`ActionMenuItem`>>, <<action-menu-group,`ActionMenuGroup`>> and <<nested-action-menu-item,`NestedActionMenuItem`>>.

[[drop-down-wrapper]]pass:[<a class="anchor" href="#drop-down-wrapper"></a>]`DropDownWrapper`::
Put your own content in an `ActionMenu`, and close the drop-down when it is used. Use it when a menu needs content that is not a list of items, such as a small form.

[[action-menu-item]]pass:[<a class="anchor" href="#action-menu-item"></a>]`ActionMenuItem`::
Add an item to an action menu. Use it for each action in an `ActionMenu`.

[[action-menu-group]]pass:[<a class="anchor" href="#action-menu-group"></a>]`ActionMenuGroup`::
Group items in an action menu. Use it to separate related actions under one heading.

[[nested-action-menu-item]]pass:[<a class="anchor" href="#nested-action-menu-item"></a>]`NestedActionMenuItem`::
Add an item that opens a nested menu. Use it when an action has several options, such as a choice of targets.

[[action-menu-move-folder]]pass:[<a class="anchor" href="#action-menu-move-folder"></a>]`ActionMenuMoveFolder`::
Show a menu to choose a folder and move items to it. Use it for a "Move to" action on mail or other items.

[[context-menu]]pass:[<a class="anchor" href="#context-menu"></a>]`ContextMenu`::
Show a menu on right-click. Pass the menu as `menu`. Use it to add actions that appear when the user right-clicks your content.

[[menu-item]]pass:[<a class="anchor" href="#menu-item"></a>]`MenuItem`::
Show a link-style item with an optional icon, for menus and navigation. Use it for an entry in a sidebar, a navigation list or a menu.

[[modal-dialog]]pass:[<a class="anchor" href="#modal-dialog"></a>]`ModalDialog`::
Show content in a modal dialog. Use it when the user must read or enter something before going on.

[[confirm-modal-dialog]]pass:[<a class="anchor" href="#confirm-modal-dialog"></a>]`ConfirmModalDialog`::
Ask a yes, no or cancel question. `onResult` gets `true`, `false` or `null`. Use it to confirm an action that is hard to undo.

[[modal-drawer]]pass:[<a class="anchor" href="#modal-drawer"></a>]`ModalDrawer`::
Show content in a drawer that closes when the user clicks outside it. Use it for a side panel that the user opens briefly and dismisses by clicking away.

[[modal-drawer-toolbar]]pass:[<a class="anchor" href="#modal-drawer-toolbar"></a>]`ModalDrawerToolbar`::
Add a title bar with an action button and a cancel button to a modal or a drawer. Use it so that your dialog has the same header as the dialogs of the Modern UI.

[[responsive-modal]]pass:[<a class="anchor" href="#responsive-modal"></a>]`ResponsiveModal`::
Show a modal dialog on wide screens and a drawer on narrow ones. Use it so one piece of content works on desktop and mobile layouts.

[[capture-before-unload]]pass:[<a class="anchor" href="#capture-before-unload"></a>]`CaptureBeforeUnload`::
Run a callback before the page is unloaded. Use it to ask the user to save or discard changes before they follow a link away from an unsaved form.

[[text-input]]pass:[<a class="anchor" href="#text-input"></a>]`TextInput`::
Show a text field. Use it for a single-line or multi-line input in a form.

[[select]]pass:[<a class="anchor" href="#select"></a>]`Select`::
Show a drop-down list to choose from. Use it when the user picks one option from a list in a form.

[[form-group]]pass:[<a class="anchor" href="#form-group"></a>]`FormGroup`::
Lay out form controls in a row or a group. Use it to give the fields of a form the spacing and alignment of the Modern UI.

[[date-input]]pass:[<a class="anchor" href="#date-input"></a>]`DateInput`::
Show a field to enter a date. Use it where the user must pick or type a date.

[[custom-time-picker]]pass:[<a class="anchor" href="#custom-time-picker"></a>]`CustomTimePicker`::
Show a field to pick a time. Use it where the user must choose a time of day.

[[address-field]]pass:[<a class="anchor" href="#address-field"></a>]`AddressField`::
Show a field to enter email addresses. Use it for recipient-style inputs, such as To, Cc or a list of addresses.

[[picker]]pass:[<a class="anchor" href="#picker"></a>]`Picker`::
Show an emoji picker. Use it to let the user insert an emoji into text.

[[tiny-mce-composer]]pass:[<a class="anchor" href="#tiny-mce-composer"></a>]`TinyMceComposer`::
Show the rich text editor used to compose messages. Use it when your Zimlet needs the same editor as the mail composer.

[[signature-box]]pass:[<a class="anchor" href="#signature-box"></a>]`SignatureBox`::
Show the editor for a signature in settings. Use it when your Zimlet lets the user edit a signature.

[[calendar-option-item]]pass:[<a class="anchor" href="#calendar-option-item"></a>]`CalendarOptionItem`::
Show a calendar's name with its color, as an option in a list. Pass the calendar as `calendar`. Use it to build a calendar choice, for example in a `Select`.

[[appointment-edit]]pass:[<a class="anchor" href="#appointment-edit"></a>]`AppointmentEdit`::
Show the calendar appointment editor. Use it when your Zimlet lets the user create or change an appointment.

[[contact-list]]pass:[<a class="anchor" href="#contact-list"></a>]`ContactList`::
Show a list of contacts. Use it to display or pick contacts in your own screen.

[[contact-editor]]pass:[<a class="anchor" href="#contact-editor"></a>]`ContactEditor`::
Show a form to edit a contact. Use it when your Zimlet lets the user create or change a contact.

[[avatar]]pass:[<a class="anchor" href="#avatar"></a>]`Avatar`::
Show a user avatar. Use it to show a person's picture or initials next to a name.

[[contact-hover-card-wrapper]]pass:[<a class="anchor" href="#contact-hover-card-wrapper"></a>]`ContactHoverCardWrapper`::
Show a contact card when the user hovers over the wrapped content. Use it around a name or an address so the user can see the contact's details.

[[folder-list]]pass:[<a class="anchor" href="#folder-list"></a>]`FolderList`::
Show the folder tree. Use it when your Zimlet needs the same folder navigation as the Modern UI.

[[folder-list-light]]pass:[<a class="anchor" href="#folder-list-light"></a>]`FolderListLight`::
Show a lighter folder list where the user selects folders. Use it in a dialog or a form where the user chooses a folder.

[[folder-list-group]]pass:[<a class="anchor" href="#folder-list-group"></a>]`FolderListGroup`::
Show a group of folders in a folder list. Use it to organize folders under a heading, such as shared folders.

[[smart-list]]pass:[<a class="anchor" href="#smart-list"></a>]`SmartList`::
Show a list with selection and keyboard navigation. Use it for a list of items that the user selects with the mouse or the keyboard.

[[infinite-scroll]]pass:[<a class="anchor" href="#infinite-scroll"></a>]`InfiniteScroll`::
Show a long list that calls `loadMore` as the user scrolls near the end, while `hasMore` is true. Use it to load a long list in pages.

[[draggable-card]]pass:[<a class="anchor" href="#draggable-card"></a>]`DraggableCard`::
Make an element draggable, and attach your `data` to the drag. Use it so the user can drag your item onto a drop target, such as a folder.

[[sidebar]]pass:[<a class="anchor" href="#sidebar"></a>]`Sidebar`, `MailSidebar`::
Show the sidebar of the Modern UI, and the sidebar of Mail. Use them when your screen needs the same sidebar layout as these views.

[[generic-mobile-ui-toolbar]]pass:[<a class="anchor" href="#generic-mobile-ui-toolbar"></a>]`GenericMobileUIToolbar`, `GenericMobileUISidebar`::
Show the toolbar of the mobile layout, with the sidebar button and the title of the current view, and its sidebar. Use them when your screen must work in the mobile layout.

[[pdfjs-viewer]]pass:[<a class="anchor" href="#pdfjs-viewer"></a>]`PdfjsViewer`::
Show a PDF. It loads on demand. Use it to preview a PDF file inside your Zimlet.

[[zimlet-slot]]pass:[<a class="anchor" href="#zimlet-slot"></a>]`ZimletSlot`::
Show a named slot. Pass its name as `name`. Use it to let other Zimlets add content inside your own screen. See xref:extending-the-ui.adoc[Extend the UI with slots].

[[zimbra-provider]]pass:[<a class="anchor" href="#zimbra-provider"></a>]`ZimbraProvider`::
Provide the host context to components below it, for `useZimbraContext`. Use it when you render a component tree of your own that must read the host context. See xref:host-context.adoc[Host context].

[[client-logo]]pass:[<a class="anchor" href="#client-logo"></a>]`ClientLogo`::
Show the logo of the Modern UI. Use it when your screen needs the product logo.

[[info-bar]]pass:[<a class="anchor" href="#info-bar"></a>]`InfoBar`::
Show a message bar. Set `isWarning` or `isSuccess` for the style. Use it to show a short notice, warning or success message in a screen.

[[error-alert]]pass:[<a class="anchor" href="#error-alert"></a>]`ErrorAlert`::
Show an error message box. Use it to tell the user that an action failed.

[[help-tooltip]]pass:[<a class="anchor" href="#help-tooltip"></a>]`HelpTooltip`::
Show a tooltip with help text. Use it to explain an icon or a control on hover.

[[certificate-modal]]pass:[<a class="anchor" href="#certificate-modal"></a>]`CertificateModal`::
Show the details of a certificate. Use it in an S/MIME or encryption flow that lets the user inspect a certificate.

[[smime-operation-drop-down]]pass:[<a class="anchor" href="#smime-operation-drop-down"></a>]`SMIMEOperationDropDown`::
Show a drop-down to choose the S/MIME operation of a message. Use it in a composer that supports signing or encrypting.

[[delete-wrapper]]pass:[<a class="anchor" href="#delete-wrapper"></a>]`DeleteWrapper`::
Wrap a Briefcase delete action. Use it when your Zimlet adds a delete control for Briefcase documents or folders.

[#enhancers]
== Enhancers

Import from `@zimbra-client/enhancers`. An enhancer wraps a component and passes it extra props.

[[with-media-query]]pass:[<a class="anchor" href="#with-media-query"></a>]`withMediaQuery(query, propName)`::
Pass whether a CSS media query matches. The prop is `matchesMediaQuery`, or the name you give. Use it to change a class component for narrow or wide screens. For a function component, use the `useMediaQuery` hook instead.

[[client-configuration]]pass:[<a class="anchor" href="#client-configuration"></a>]`clientConfiguration(paths)`::
Pass values from the client configuration. It takes the same argument as `useClientConfig`. Use it to read configuration in a class component. For a function component, use `useClientConfig`.

[[with-tracking]]pass:[<a class="anchor" href="#with-tracking"></a>]`withTracking()`::
Pass the tracking object as props. Use it to send usage events from a class component. For a function component, use `useTracking`.

[[with-tab-manager]]pass:[<a class="anchor" href="#with-tab-manager"></a>]`withTabManager(mapPropsToTab)`::
Give a component the functions to open tabs. Use it when your component opens an item in a new tab of the Modern UI.

[[with-intl-consumer]]pass:[<a class="anchor" href="#with-intl-consumer"></a>]`withIntlConsumer(mapProps)`::
Pass the translation context as props, or the result of `mapProps`. Use it when a class component needs the current language data. See xref:localization.adoc[Localization].

[[with-intl-wrapper]]pass:[<a class="anchor" href="#with-intl-wrapper"></a>]`withIntlWrapper(zimletLocale)`, `withZimletIntlWrapper(zimletLocale)`::
Provide your Zimlet's own language files to the component. Both names are the same function. `zimletLocale.importFn` returns the import of your locale file. Use it to translate the text of a component of your Zimlet. See xref:localization.adoc[Localization].

== GraphQL module
