= Reference

The reference holds the complete facts about the `zimlet` commands and the files of a xref:reference/glossary.adoc#zimlet[Zimlet]. It also covers the fields of the context, the shared modules and the slots. It has no tutorial text. Use it when you need an exact name, option, signature or default, and follow the links in the guide for the explanation.
