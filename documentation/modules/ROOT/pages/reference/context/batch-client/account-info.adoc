= accountInfo

Reads the account information of the signed-in user. Use it when your Zimlet needs the name of the user, an account attribute or the Zimlets of the account, for example to turn a feature on or off by an account setting.

[#signature]
== Signature

[source,js]
----
zimbraBatchClient.accountInfo()
----

[#parameters]
== Parameters

None.

[#returns]
== Returns

A promise for an object with the account `name`, `attrs` (the account attributes, with the strings `"true"` and `"false"` converted to booleans) and `zimlets`. The promise rejects when the request fails.

[#usage-notes]
== Usage notes

* In a handler, prefer the `useAccountInfo` hook. See xref:reference/apis-hooks.adoc[APIs and hooks].
* Call it once and keep the result, because each call sends a request.
