= Command handler

Runs a function when a command is triggered. Use it to give a command a behaviour that runs when the user presses its key. Take the field from the context first, as in `const { shortcutCommandHandler } = context;`. The Modern UI calls its `handleKeyDown` and `handleKeyUp` methods for key events, so a Zimlet does not call them. A handler runs only for a command that has a binding. See xref:reference/context/keyboard-shortcuts/key-bindings.adoc[Key bindings].
