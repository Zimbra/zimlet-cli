= addCommandHandlers

Adds functions that run when a command is triggered. Use it to give a command a behaviour, such as opening a dialog of your Zimlet when the user presses its key. Use it together with xref:reference/context/keyboard-shortcuts/key-bindings/add-bindings.adoc[addBindings], which binds the key to the command.

[#signature]
== Signature

[source,js]
----
shortcutCommandHandler.addCommandHandlers(commandHandlers)
----

[#parameters]
== Parameters

[cols="2,2,6"]
|===
|Name |Type |Description

|`commandHandlers`
|array of object
|Each object has `context` (string), `command` (string) and `handler` (function `(info: { e?: KeyboardEvent, context: string, command: string }) => void`). The handler is called with `info`. `e` is the event of the key release. It is missing when the command comes from a sequence of keys that ended after its delay. Its return value is ignored.

|===

[#returns]
== Returns

Nothing (`undefined`).

[#usage-notes]
== Usage notes

* Handlers of a specific context run first. Handlers of the `all` context run only when none of the others ran.
* Keep the objects in a variable if you want to remove them later with xref:reference/context/keyboard-shortcuts/command-handler/remove-command-handlers.adoc[removeCommandHandlers].
* A command that no binding points to never runs.
