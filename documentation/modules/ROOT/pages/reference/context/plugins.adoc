= Plugins

Add and remove the xref:fundamentals/extending-the-ui.adoc[plugin handlers] of your Zimlet. Use it to extend the Modern UI: it is how a Zimlet adds its content to a slot. Take the field from the context first, as in `const { plugins } = context;`. A handler is a function, or any other value, that you register under a key. For a slot the key has the form `slot::<slot-name>`, and the slot calls the handler to get what it shows. See xref:fundamentals/extending-the-ui.adoc[Extend the UI with slots].

[#members]
== Members

[[register]]pass:[<a class="anchor" href="#register"></a>]xref:reference/context/plugins/register.adoc[`register(name, handler)`]::
Adds a handler under a key.

[[unregister]]pass:[<a class="anchor" href="#unregister"></a>]xref:reference/context/plugins/unregister.adoc[`unregister(name, handler)`]::
Removes one handler that you registered.

[[unregister-all]]pass:[<a class="anchor" href="#unregister-all"></a>]xref:reference/context/plugins/unregister-all.adoc[`unregisterAll()`]::
Removes every handler that your Zimlet registered.
