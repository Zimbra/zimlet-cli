= Store

The Redux store of the Modern UI. Use it to read the state that the Modern UI holds, to change it with actions, or to react to its changes. Take the field from the context first, as in `const { store } = context;`. It has the standard methods `getState`, `dispatch` and `subscribe`. Its extra member `zimletRedux` adds your own state, actions and selectors. See the https://redux.js.org/api/store[Redux documentation^] for the standard methods.
