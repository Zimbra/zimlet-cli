= subscribe

Runs a function after every action that is dispatched to the store. Use it when your Zimlet must react to a change of the state, for example to wait until the account has loaded and then do something once.

[#signature]
== Signature

[source,js]
----
store.subscribe(listener)
----

[#parameters]
== Parameters

[cols="2,2,6"]
|===
|Name |Type |Description

|`listener`
|function
|Called with no arguments after each dispatched action. Read the state inside it with `store.getState()`.

|===

[#returns]
== Returns

A function. Call it to stop listening.

[#usage-notes]
== Usage notes

* This is the standard Redux method.
* The listener runs after every action, also those of other Zimlets. Keep it short, and check the part of the state that you care about.
* Stop listening when you have what you need, so the listener does not run for the whole session.
