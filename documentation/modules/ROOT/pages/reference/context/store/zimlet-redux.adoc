= Zimlet state

Adds your own state, actions and selectors to the store, and reads those of the Modern UI and of other Zimlets. Use it when your Zimlet needs state that its handlers, or other Zimlets, share. Take it from the store first, as in `const { zimletRedux } = context.store;`. Your reducer keeps the state, your actions change it, and your selectors read it. Other code can then use them through `zimletRedux.actions` and `zimletRedux.selectors`.
