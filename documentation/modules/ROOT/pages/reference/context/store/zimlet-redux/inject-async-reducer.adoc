= injectAsyncReducer

Adds a Redux reducer under a key of the state tree. Use it when your Zimlet needs state of its own that its handlers share, such as a counter or a selection, and you want to change it with `dispatch` and read it with `getState`.

[#signature]
== Signature

[source,js]
----
store.zimletRedux.injectAsyncReducer(namespace, reducer)
----

[#parameters]
== Parameters

[cols="2,2,6"]
|===
|Name |Type |Description

|`namespace`
|string
|The key of the state tree, so the state is at `state[namespace]`.

|`reducer`
|function
|A Redux reducer, `(state, action) => newState`. Give `state` a default value.

|===

[#returns]
== Returns

Nothing (`undefined`).

[#usage-notes]
== Usage notes

* Start the namespace with the name of your Zimlet. A reducer of the Modern UI with the same key wins, and yours is ignored.
* Calling it again with the same namespace replaces your reducer. You cannot remove a reducer.
* The state is not kept after a page reload.
