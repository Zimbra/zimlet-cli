= removeActions

Removes the action creators that you published under a namespace. Use it when your Zimlet stops offering them, for example when it turns a feature off, so that other code can no longer use them.

[#signature]
== Signature

[source,js]
----
store.zimletRedux.removeActions(namespace)
----

[#parameters]
== Parameters

[cols="2,2,6"]
|===
|Name |Type |Description

|`namespace`
|string
|The namespace that you gave to xref:reference/context/store/zimlet-redux/add-actions.adoc[addActions].

|===

[#returns]
== Returns

Nothing (`undefined`).

[#usage-notes]
== Usage notes

* Nothing happens when the namespace has no actions.
* It removes only published actions. Reducers stay.
