= zimbraOrigin

The prefix for the addresses of server requests. Use it when your Zimlet builds the address of a server path itself, for example for a `fetch` call. The prefix depends on the installation, so read it from the context and do not write it in your code.

[#signature]
== Signature

[source,js]
----
context.zimbraOrigin
----

[#type]
== Type

string. It comes from the Modern UI configuration. Depending on the installation, it is a path such as `/@zimbra` or a full origin.

[#usage-notes]
== Usage notes

* Put it in front of a server path to build the address of a request.
* For the batch client, xref:reference/context/batch-client/resolve.adoc[resolve] does the same.
