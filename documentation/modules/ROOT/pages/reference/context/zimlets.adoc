= Zimlet manager

The Zimlet manager of the Modern UI. Use it when your Zimlet must work with other Zimlets or react to the loading of the Zimlets. Take the field from the context first, as in `const { zimlets } = context;`. It calls plugin handlers, tells whether a slot is in use, and raises events when the Zimlets have loaded or when a handler is added or removed. App events, such as sending a message, are a different thing. See xref:go-deeper/app-events.adoc[App events].

WARNING: Use `zimlets.on` only for the events on this page. Do not use it to pass data between Zimlets or between a Zimlet and the Modern UI. A listener that starts late misses what was sent earlier, and nothing keeps the value. Share data through the Redux store instead. See xref:go-deeper/redux.adoc[Shared state with Redux].
