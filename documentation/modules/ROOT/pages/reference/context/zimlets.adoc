= Zimlet manager

The Zimlet manager of the Modern UI. Use it when your Zimlet must work with other Zimlets or react to the loading of the Zimlets. Take the field from the context first, as in `const { zimlets } = context;`. It calls plugin handlers, tells whether a slot is in use, and sends events to the Modern UI and to Zimlets. App events, such as sending a message, are a different thing. See xref:go-deeper/app-events.adoc[App events].
