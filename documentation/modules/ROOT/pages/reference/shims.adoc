= Shared modules

Find every module that a xref:reference/glossary.adoc#zimlet[Zimlet] can import from the xref:reference/glossary.adoc#modern-ui[Modern UI] instead of bundling its own copy, and the page that lists its exports. Use it to check that a module is shared, and to find the components, hooks and helper functions you can reuse. It matters because a Zimlet that imports a name the Modern UI does not share fails to load.

The xref:fundamentals/shared-libraries.adoc[Shared libraries] page explains how shared modules work. Each page below lists the names that you can import from its modules.
