= All slots A to Z

Every extension point of the xref:reference/glossary.adoc#modern-ui[Modern UI] in one alphabetical list: 134 slots and 9 data keys, each with a link to its entry. Use it when you already know a name, such as one from a Zimlet you read or from the browser console. To browse by screen instead, start from xref:reference/slots.adoc[Slots and extension points].

You register a slot as `slot::<name>`, and the names here have no prefix. A data key has no prefix, so it appears as you register it. The names that repeat for each xref:reference/glossary.adoc#vertical[vertical] share one entry, such as `<vertical>-tab-item`. See xref:fundamentals/extending-the-ui.adoc[Slots and handlers] for how handlers work.
