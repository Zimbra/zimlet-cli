= Ad slots

The ad slots are places in the xref:reference/glossary.adoc#modern-ui[Modern UI] that reserve room for advertisements. Ten of them are boxes of a fixed size at the right and left of the screen and along the bottom edge of the window. Two more are at the top of lists. Use them when your xref:reference/glossary.adoc#zimlet[Zimlet] shows an advertisement, or another block of a fixed size, without moving the content of the screen. xref:fundamentals/extending-the-ui.adoc[Slots and handlers] explains how a handler fills a slot.

[#before-you-register-a-handler]
== Before you register a handler

[#ad-boxes]
=== Ad boxes

The ten slots with the prefix `adSlot-` draw in three places. The names carry the size of the standard banner that fits the box.

* The right column is at the right of the screens of Mail, Calendar and its search results, and Contacts. The sidebars of the same screens have the left column below their folders. Both show only in a window at least 1300 px wide.
* The bottom strip is fixed to the bottom edge of the window, in every screen. It shows only in a window up to 1024 px wide. A window up to 768 px wide has the strip of `adSlot-adhesion-320-50`. A window from 769 to 1024 px wide has the strip of `adSlot-adhesion-728-90`.

The boxes of the right and left columns cut off content that is taller than the maximum height. The boxes are listed in the order in which they appear, from top to bottom.

[#handlers-of-the-ad-slots]
=== Handlers of the ad slots

The Modern UI calls the handler of every ad slot with the value `true`, so the slots have no props. Return an element, or `null` to draw nothing. A slot without a handler takes no room in the columns.

[#adslot-300-250-top]
== adSlot-300-250-top

Adds a box at the top of the right column, 300 px wide and up to 250 px high. Use it for a banner of the standard 300 by 250 size. Use <<adslot-300-250-bottom,`adSlot-300-250-bottom`>> for a second box of that size under it.

[#adslot-300-250-top-register-a-handler]
=== Register a handler

[source,js]
----
plugins.register('slot::adSlot-300-250-top', handler)

// handler: () => element | null
----

[#adslot-300-250-top-props]
=== Props

None.

[#adslot-300-250-top-usage-notes]
=== Usage notes

* The right column shows in Mail, in Calendar and its search results, and in Contacts, in a window at least 1300 px wide. See <<ad-boxes,Ad boxes>>.

[#top-mail-ad-item]
== top-mail-ad-item

Adds a block above the first row of a list, and above the message of an empty list. Use it for a banner that belongs at the top of a list of items. Despite its name, the slot is not only in Mail. Use <<top-mail-generic-slot,`top-mail-generic-slot`>> for a block inside the message list of Mail.

[#top-mail-ad-item-register-a-handler]
=== Register a handler

[source,js]
----
plugins.register('slot::top-mail-ad-item', handler)

// handler: () => element | null
----

[#top-mail-ad-item-props]
=== Props

None.

[#top-mail-ad-item-usage-notes]
=== Usage notes

* The block shows above the first row of the message list of Mail, the list of Contacts and the file list of Briefcase. It also shows above the empty message of these lists, and above the empty message of the message list in Mail.
* The block shows above the calendar and the list of tasks in Calendar, and above the results on the search screen of Calendar.
* The block also shows above the first row of the lists in three dialogs. They are the contact picker, the dialog that attaches a message in the composer, and the dialog that recovers deleted items.
* The handler cannot tell which list it is in. Every handler shows its content in every place.
* The block is cut off at the height of a narrow row, 72 px.

[#top-mail-generic-slot]
== top-mail-generic-slot

Adds a block as the first row of the message list of Mail, below <<top-mail-ad-item,`top-mail-ad-item`>>. Use it for a block that belongs inside the list. It also shows above the message of an empty list.

[#top-mail-generic-slot-register-a-handler]
=== Register a handler

[source,js]
----
plugins.register('slot::top-mail-generic-slot', handler)

// handler: ({ wide }) => element | null
----

[#top-mail-generic-slot-props]
=== Props

[[top-mail-generic-slot-wide]]pass:[<a class="anchor" href="#top-mail-generic-slot-wide"></a>]`wide` (boolean)::
`true` when the message list uses the wide layout. That is when the window is at least 769 px wide and the reading pane is not at the right of the list. The slot passes no props above the empty message of a list.

[#top-mail-generic-slot-usage-notes]
=== Usage notes

* The slot is in the message list of Mail only, including search results. The block has no height limit.
