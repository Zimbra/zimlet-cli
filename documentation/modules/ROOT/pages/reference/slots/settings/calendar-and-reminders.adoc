= Calendar and reminders

These slots hide controls of the Calendar and Reminders page of the Settings dialog, and add one control after the reminder options. Use them when a deployment must remove a calendar option, or when a Zimlet has a calendar option of its own. To add a section of your own, use the `settings` key, as xref:reference/slots/settings/dialog-sections.adoc[Dialog sections] describes.

[#before-you-register-a-handler]
== Before you register a handler

[#slots-that-hide-a-control]
=== Slots that hide a control

Six of the slots hide a built-in control and add nothing. The Modern UI checks only whether a handler returned a value. It does not draw the value.

WARNING: A handler that returns a value hides the control for every user who has the Zimlet. Return `null` when your Zimlet does not apply, and the Modern UI keeps the control.

[#default-calendar-setting]
== default-calendar-setting

Hides *Default Calendar*, the list that sets the calendar for new events and invitations. See <<slots-that-hide-a-control,Slots that hide a control>>.

[#default-calendar-setting-register-a-handler]
=== Register a handler

[source,js]
----
plugins.register('slot::default-calendar-setting', handler)

// handler: () => true | null
----

[#default-calendar-setting-props]
=== Props

None.

[#default-calendar-setting-usage-notes]
=== Usage notes

* The control appears only when the account has more than one calendar that can hold new events. The slot is used only then.

[#calendar-and-reminders-video-call-preferences]
== calendar-and-reminders-video-call-preferences

Adds a control in the *Event Reminders* block, after *Show Reminders for Past-Due Events* and before *Free Busy Permission*. Use it for an option of your Zimlet that belongs with the calendar options, such as a preference for video calls.

[#calendar-and-reminders-video-call-preferences-register-a-handler]
=== Register a handler

[source,js]
----
plugins.register('slot::calendar-and-reminders-video-call-preferences', handler)

// handler: ({ value, onFieldChange }) => element | null
----

[#calendar-and-reminders-video-call-preferences-props]
=== Props

[[calendar-and-reminders-video-call-preferences-value]]pass:[<a class="anchor" href="#calendar-and-reminders-video-call-preferences-value"></a>]`value` (object)::
The values of the fields of the Calendar and Reminders page, by field name. Read only your own field. See xref:reference/slots/settings/dialog-sections.adoc#settings-prop-value[Component props].

[[calendar-and-reminders-video-call-preferences-on-field-change]]pass:[<a class="anchor" href="#calendar-and-reminders-video-call-preferences-on-field-change"></a>]`onFieldChange` (function `(fieldName: string) => (event: object) => Promise`)::
Reports a change to one of your fields. See xref:reference/slots/settings/dialog-sections.adoc#settings-prop-on-field-change[Component props].

[#calendar-and-reminders-video-call-preferences-usage-notes]
=== Usage notes

* Add your field to the page with the `settings` key and the page `id` `calendarAndReminders`. The dialog saves only fields that it knows.
